# 🌐 labs-telematica

Repositorio de **recursos de apoyo académico** para las áreas de **Networking** e **Información Security**.  
Perteneciente a los proyectos curriculares de **Tecnología en Sistematización de Datos** e **Ingeniería Telemática** de la **Universidad Distrital Francisco José de Caldas**.

## 🎯 Objetivo

Centralizar tutoriales, laboratorios y material práctico que facilite el aprendizaje de los estudiantes en temas como:

- Configuración de redes (Cisco IOS, Routing & Switching)
- Simulación de redes (GNS3, Packet Tracer, EVE-NG)
- Análisis de tráfico (Wireshark, tcpdump)
- Seguridad ofensiva y defensiva
- Automatización con Python/Ansible

## 📖 Estructura del repositorio

```
📁 images/    → Capturas, diagramas de topologías, logos
📁 docs/      → Tutoriales y guías paso a paso de instalación/configuración
📁 labs/      → Prácticas y laboratorios listos para realizar en clase
```
